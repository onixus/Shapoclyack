# Shapoclyack 0.50-1124

Стабильный релиз от **24 ноября 2026**. Собран из `main` на коммите `26e27153`
(после PR #676). Сменяет кандидат `shapoclyack-0.49-1111-rc1` от 11 ноября.
Последний предыдущий стабильный релиз — `shapoclyack-0.48-1021`.

Заметки ниже написаны для того, кто ставит и сопровождает платформу, а не для
разработчика. Технический перечень — в [CHANGELOG.md](../../CHANGELOG.md).

## Что изменится для людей, которые работают в консоли

- **Ответ оператора читается как текст, а не как карточка данных.** Пояснение
  к предложению и к разбору теперь на обычном языке. Ссылка из ответа ведёт
  туда, куда её разрешил сервер: на найденную уязвимость, если она ещё одна и
  та же, иначе на опубликованный прогон. Чужой тенант и чужой снимок так открыть
  нельзя.
- **План устранения открывается с выбранным исправлением.** У шага виден
  ответственный, и им может быть не только адрес почты. Принять план можно
  только тем подтверждением, которое к нему относится.
- **Сводка скана в PDF — по-русски и с именем площадки.** Колонка находок
  показывает имя и порт, адрес — в скобках. Русские буквы больше не
  превращаются в знаки вопроса: в образ сканера добавлен шрифт DejaVu. Если
  файл сводки не собрался, консоль не предлагает его скачать.
- **Отчёт о соответствии называет пункт регулятора, а не внутренний шифр.**
  В колонке нормативной ссылки — пункт или мера (`п. 3.3 № 117`,
  `№ 239 АУД.2`). Метки каталога остаются внутренними. Контроль без исходных
  данных подписан «нет исходных данных» и не выглядит как вердикт регулятора.
- **Рядом с адресом виден домен, который сканировали.** В ответе API записи
  уязвимости сохраняют основное имя и адрес.
- **Снимки веб-страниц снова доступны, но только через отдельный воркер.**
  Браузер запускается в изолированном процессе, не в образе сканера. Стадия
  выключена, пока её явно не включат и не укажут адрес воркера. Без воркера
  скан идёт как обычно и просто не делает снимков. Снимки видят оператор и
  администратор.

## Что изменится для того, кто ставит и сопровождает

- **Лицензия продукта.** Появились офлайн-генератор лицензии, загрузка
  подписанного файла через `/api/license` и страница `/license`. Пока
  `OCTO_LICENSE_ENFORCEMENT_ENABLED` не включён, установка без файла лицензии
  работает как раньше. Когда проверка включена и срок лицензии вышел, новый
  скан не стартует, а плановый запуск откладывается, а не пропускается.
- **Слежение за похожими именами (Brand Watch).** Платформа может следить за
  именами, похожими на ваши, за пределами области сканирования. Список правит
  оператор. Это отдельная миграция `0107_brand_watch`.
- **Полный состав в Docker Compose.** `compose.full.yml` поднимает
  распределённый стенд, а запрос к несуществующему `/api/...` получает ответ
  API, а не пустую страницу.
- **Установщик честнее говорит про занятый каталог.** Подсказка, что каталог
  уже занят, теперь безопасна для копирования и объясняет, что чистить.
- **Проверка безопасности в сборке.** Сборка гоняет OWASP ZAP по API того же
  образа. Предупреждение или провал роняют сборку, отчёты сохраняются в любом
  случае. На стенде проверки старт сканов выключен.
- **Закрыты уязвимости Kerberos в базовых пакетах Debian.** Образы ставят
  исправленные `libkrb5-3`, `libk5crypto3` и `libgssapi-krb5-2`.

Движок проб не менялся: это по-прежнему подписанный Pulse `v1.5.0`. Набор
находок из-за смены движка не должен поехать.

## Обновление

1. Снимите дайджесты опубликованных образов и поставьте `tag@sha256`, не
   голый тег и не `latest`. Стабильный релиз двигает `latest`; на него
   полагаться не нужно.
2. Остановите новые сканы на время миграции. Схема применяется сама при
   старте API: `0107_brand_watch`, затем `0108_product_licenses`.
3. После старта `GET /api/system` должен ответить версией `0.50-1124`.
   Сенсоры этой версии не должны помечаться устаревшими.
4. Лицензию включать не обязательно. Если включаете — сначала загрузите
   подписанный файл и задайте `OCTO_LICENSE_PUBLIC_KEY`, и только потом
   `OCTO_LICENSE_ENFORCEMENT_ENABLED`.
5. Снимки страниц сами не включатся. Нужен отдельный `screenshot-worker` и
   явный адрес `SCREENSHOT_WORKER_URL`.

Откат — это возврат на образы предыдущего релиза, а не смешивание. Схему
`0108` назад миграция не откатывает сама: перед обновлением снимите резервную
копию базы.

      latest» и проверка ключа подписи.
- [ ] Опубликовать с `DRY_RUN=false`. Записать три дайджеста индекса и
