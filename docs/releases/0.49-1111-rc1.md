> **No Nmap.** The images contain no Nmap binaries or NSE data, and the scanner
> no longer runs Nmap at all: configs that name the Nmap backend or
> `nmap_timing` are refused. Only three images are published (scanner, api,
> aio). See [Migrating off Nmap](../nmap-migration.md).

## Changes since 0.48-1021

- **Security & Integrity:**
  - Patched `nuclei` builder against `go-jose/v4` v4.1.6 to close CVE-2026-116587 (DoS via crafted RSA parameters in JWKs).
  - Enforced SAML Single Logout (SLO) subject binding and pending request validation (`0105`, `0106`).

- **Pulse & Service Probing:**
  - Completed Rhai Pulse plugin phases 1 through 9: 60+ unauthenticated read-only probe checks across infrastructure, web services, ICS/SCADA (Modbus, EtherNet/IP), and protocols (SMB, Cassandra, MSSQL, Oracle TNS, RMI, EPMD, iSCSI, DRDA, GIOP).
  - Rhai plugins decoupled from container layers: plugins are now versioned git content managed via `scripts/fetch-pulse-plugins.sh` into `service_probe.pulse.plugins_dir`.
  - Added support for Pulse report schema v3 while keeping backward compatibility with v2.

- **FSTEC / 187-FZ Compliance & BDU Threats:**
  - Added BDU threat mappings and FSTEC / 187-FZ compliance reporting frameworks (`api/services/bdu_threats.py`, `scripts/fetch-bdu-threats.py`).

- **AI Operator & Remediation Campaigns:**
  - Added `xai` and generic `openai_compatible` AI operator providers with strict public endpoint verification.
  - Added Aggregated Problems and Remediation Campaigns (`/api/problems`, `/api/remediation-campaigns`) with verified lifecycle stages.
  - APEX console UI enhancements: unified navigation tabs, 1440px multi-stage board, and dark/light themes.

- **Engine & Infrastructure:**
  - L2 discovery enhancements with neighbour table limits configuration script (`scripts/neigh-table-limits.sh`).
  - Native RDP X.224 perimeter observations (`octo.perimeter_observation.v1`).
  - Multi-arch build and publication enhancements via Jenkins.
